# Catch Train 설치 안내

받으신 `Catch-Train-x.y.z.apk` 파일을 안드로이드 휴대폰에 설치하는 방법입니다.

## 1. 준비

- **안드로이드 8.0 이상** 휴대폰 (아이폰은 지원하지 않습니다)
- 코레일(레츠코레일) 홈페이지 로그인 계정

## 2. 설치

1. 받은 `.apk` 파일을 휴대폰에서 엽니다 (카톡·드라이브·문자 등 어디로 받아도 됩니다).
2. **"이 출처의 앱은 설치할 수 없습니다"** 같은 경고가 뜹니다. 정상입니다.
   플레이스토어를 거치지 않는 앱은 모두 이 경고가 뜹니다.
3. `설정` 을 누르고 → **"이 출처 허용"** 을 켠 뒤 뒤로 돌아옵니다.
   (파일을 연 앱 — 카톡이나 브라우저 — 에 한 번만 허용하면 됩니다.)
4. `설치` 를 누릅니다.
5. 설치가 끝나면 **"Catch Train"** 앱이 생깁니다.

> 기종에 따라 `설정 → 앱 → 특별한 접근 권한 → 알 수 없는 앱 설치` 에서
> 미리 허용해 둘 수도 있습니다.

## 3. 첫 실행

1. 앱을 켜면 **알림 권한**을 물어봅니다. 반드시 **허용**해 주세요.
   좌석이 열렸을 때 알려주는 통로입니다.
2. 앱 안에 코레일 홈페이지가 그대로 뜹니다. **여기서 직접 로그인**합니다.

## 4. 쓰는 순서

1. 앱 안의 코레일 화면에서 **평소처럼 직접 조회**합니다 (구간·날짜·시간).
2. 조회 결과가 나오면 앱이 그 목록을 읽어 **`열차 선택`** 목록으로 보여줍니다.
3. 원하는 **열차 + 좌석 등급 칸을 체크**합니다. (일반실이 왼쪽, 특실이 오른쪽 — 사이트와 같은 순서)
4. **`감시 시작`** 을 누릅니다. 앱이 알아서 새로고침하며 지켜봅니다.
5. 체크한 자리가 열리면 **알림이 오고, 그 칸을 고른 뒤 화면 아래 `예매` 버튼까지 대신 눌러줍니다.**
6. **좌석 고르기와 결제는 직접 하셔야 합니다.** 여기까지가 앱이 하는 일입니다.

> `예약대기 신청` 이나 `입석+좌석 예매` 는 **앱이 누르지 않습니다.** 그런 버튼이 뜨면
> 좌석 칸만 골라 둔 채 멈추고 알림을 보냅니다. 마지막 `예매` 는 직접 눌러 주세요.

## 5. 꼭 알아두실 점

- **앱을 켜 둔 채로 두셔야 합니다.** 홈으로 나가거나 다른 앱을 쓰면 감시가 멈춥니다.
  감시 중에는 화면이 저절로 꺼지지 않으니, **충전기를 꽂아두고** 화면을 켜 두세요.
- **아이디·비밀번호를 앱이 저장하지 않습니다.** 코레일 홈페이지에 직접 로그인하는 방식이라,
  로그인 정보는 앱을 만든 사람도 볼 수 없습니다.
- 한참 두면 코레일 쪽 로그인이 자동으로 풀립니다. `세션 만료` 가 뜨면 다시 로그인해 주세요.
- 새로고침 간격을 너무 짧게 두면 코레일 쪽에서 접속을 막을 수 있습니다. 기본값을 권합니다.
- `예매` 자동 클릭이 부담스러우면 설정에서 끌 수 있습니다. 끄면 알림만 옵니다.

## 6. 업데이트

새 버전 `.apk` 파일을 받아 **그냥 다시 설치**하면 됩니다. 기존 앱 위에 덮어써지고
설정은 유지됩니다. (지우고 다시 깔 필요 없습니다.)

## 7. 안 될 때

- 설치가 안 됨 → 안드로이드 버전이 8.0 이상인지 확인
- "패키지 파싱 오류" → 파일이 중간에 잘려 받아진 경우입니다. 다시 받아주세요.
- 알림이 안 옴 → `설정 → 앱 → Catch Train → 알림` 이 켜져 있는지 확인
