# Catch Train — 크롬 확장 (작업 시작 단계)

같은 목적의 PC 판. 코레일 조회 결과 화면을 감시하다가 체크해 둔 칸이 열리면 알리고
그 칸을 골라 [예매] 를 눌러 준다.

**지금은 골격뿐이다.** `chrome://extensions` → `개발자 모드` → `압축해제된 확장 프로그램을 로드`
에 이 폴더를 넣으면 로드되고, content script 가 콘솔에 한 줄 찍는 것 말고는 아무것도 하지 않는다.

---

## 먼저 읽을 것

플랫폼과 무관한 것은 전부 저장소 공통 문서에 있다. **여기에 복사하지 말 것.**

| | |
|---|---|
| [`../CLAUDE.md`](../CLAUDE.md) | **대원칙.** 재시도 금지 · [예매]까지만 · 조회 조건은 앱이 안 갖는다 |
| [`../docs/DESIGN.md`](../docs/DESIGN.md) | 특히 **§38 (코레일 DOM 실측)** 과 **§39 (대기열)**. 확장에도 그대로 적용된다 |
| [`../shared/`](../shared/) | selector 단일 출처 |

대원칙은 안드로이드 규칙이 아니라 **제품의 규칙**이다. 확장이라고 예외가 되지 않는다.

## 안드로이드와 갈리는 지점

옮겨 오면 안 되는 것과, 새로 정해야 하는 것.

### 1. `el.click()` 은 여기서도 안 된다

content script 의 합성 이벤트도 `isTrusted = false` 다. WebView 와 똑같은 벽이다.
크롬에서 신뢰된 입력을 만드는 길은 `chrome.debugger`(`Input.dispatchMouseEvent`) 뿐인데,
그러면 **"…에서 이 브라우저를 디버깅하고 있습니다" 배너가 상시로 뜨고** 웹스토어 심사에서도
눈에 띈다. 안드로이드의 `MotionEvent` 자리는 **그대로 옮겨올 수 없고 다시 설계해야 한다.**

### 2. 갱신은 훨씬 쉽다

안드로이드가 새로고침(F5)으로 간 이유는 모바일 폭에 [열차조회] 버튼이 없어서다 (§38-9).
PC 폭에서는 그 버튼이 실제로 보인다. 그래도 **누르는 방법이 1번 문제에 걸리므로**
`location.reload()` 가 여전히 가장 현실적이다. 조회 조건은 `localStorage["LS_TICKET_GENERAL"]`
에 있어 새로고침해도 살아남는다 (§38-9) — 이건 브라우저에서도 같다.

### 3. 화면이 보여야 한다는 제약이 약해진다

안드로이드는 "사람이 볼 수 없으면 갱신하지 않는다" 가 대원칙 1의 따름정리였다.
확장은 백그라운드 탭에서도 DOM 을 읽을 수 있다. **그렇다고 제약을 풀지 말 것** —
사람이 보지 않는 채로 도는 감시가 바로 대원칙 2가 막으려던 그 요청이다.
탭이 살아 있어야 한다는 선은 유지한다.

### 4. 주기 관리를 어디서 하나

`chrome.alarms` 는 최소 30초에 무작위 흔들기가 어렵고, service worker 는 30초쯤 놀면 죽는다.
content script 의 타이머는 탭과 함께 살지만 페이지 새로고침마다 초기화된다.
**아직 정하지 않았다.** 대원칙 7(사이클마다 무작위 간격)을 만족하는 쪽으로 고를 것.

### 5. 알림

`chrome.notifications`. 안드로이드의 `NotificationChannel` / 결제 재촉 알림(§19-3)에
해당하는 것을 다시 만들어야 한다.

## 정해야 할 것

- [ ] 주기 관리 위치 (위 4번)
- [ ] 2단계 예매 클릭을 신뢰된 이벤트로 만드는 방법, 또는 **알림까지만 하고 클릭은 사람에게 넘기는 안**
- [ ] selector 를 `shared/` 에서 어떤 형식으로 가져올지 ([`../shared/README.md`](../shared/README.md))
- [ ] 빌드 도구를 둘지 (지금은 없다 — 번들러 없이 순수 ES 모듈로 갈 수 있으면 그게 낫다)
- [ ] 웹스토어에 올릴지, 압축해제 로드로만 쓸지
  (안드로이드는 Play 스토어를 포기했다 → [`../android/RELEASE.md`](../android/RELEASE.md))

## 구조 (계획)

```
extension/
├── manifest.json
└── src/
    ├── background.js   ← 감시 루프 (안드로이드 watcher/WatchController)
    ├── content.js      ← DOM 판독 (안드로이드 webview/KtxParserScript)
    ├── domain/         ← 순수 판정 로직 (안드로이드 domain/ 과 같은 규칙)
    └── ui/             ← 팝업 / 칸 체크 UI
```

`domain/` 은 안드로이드 쪽과 마찬가지로 **DOM 도 chrome API 도 모르는 순수 코드**로 둔다.
DESIGN.md §32 가 요구하는 것이 이것이다.
